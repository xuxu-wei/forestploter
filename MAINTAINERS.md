## Current maintainer

## Responsibilities

The maintainer owns public API decisions, release approval, PyPI and GitHub
permissions, security reports, dependency updates, documentation quality, and
visual-regression review.

## Release authority

Only a maintainer may approve the protected `pypi` GitHub environment or alter
the PyPI Trusted Publisher configuration. Release artifacts must be built by
the repository workflow from a reviewed tag; local API tokens are not used.

When a maintainer leaves, review GitHub access, branch protection, environments,
PyPI owners and maintainers, Trusted Publishers, documentation deployment, and
security contacts before removing the account.
