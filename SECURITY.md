# Security policy

## Supported versions

| Version | Supported |
|---|---|
| Latest `0.1.x` release | Yes |
| Older prereleases and development snapshots | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory form:

https://github.com/xuxu-wei/forestploter/security/advisories/new

Include affected versions, a minimal reproduction, expected impact, and any
known mitigation. The maintainer will acknowledge a complete report as soon
as practical, investigate it privately, and coordinate a fix and disclosure.

Security fixes may be released outside the normal deprecation policy when
protecting users requires an immediate compatibility change.
